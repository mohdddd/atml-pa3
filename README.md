# ATML PA3 — Fine-Tuning, Visual Grounding, and Test-Time Compute

Code, configurations, split/example IDs, environment specification and machine-readable results for
Programming Assignment 3 of EE-5102/CS-6304 *Advanced Topics in Machine Learning* (Fall 2026).

| Task | Topic | Status |
|---|---|---|
| 1 | LLM fine-tuning of Qwen3-0.6B on MetaMathQA: Full FT, Full FT + L2-SP, LoRA-4, LoRA-16, OPLoRA-16 | not started |
| 2 | SigLIP → MLP connector → Qwen3-0.6B VLM, 3-stage curriculum, grounding with complementary pairs | not started |
| 3 | Test-time compute: Best-of-N, self-consistency, self-certainty, VisConf/RWC, refinement, adaptive sampling | not started |

All experiments run on **Kaggle, 2× NVIDIA T4 (16 GB, no BF16)**, hence FP16 autocast with dynamic loss
scaling everywhere. Global seed **6304**.

## Repository layout

```
pa3/                    importable package (pip install -e .)
  common/               paths, seeding/RNG state, JSONL logging, env report, GitHub push, HF Hub backup
  task1/                data prep, trainer (Full FT / L2-SP / LoRA / OPLoRA), eval, diagnostics
  task2/                feature caching, connector + VLM wrapper, data builders, curriculum trainer, eval
  task3/                rollout loading, answer grouping, scoring/selection, live generation, adaptive stopping
configs/task{1,2,3}/    YAML configs — the exact settings used for every reported number
scripts/                CLI entry points (one per pipeline step)
kaggle/                 Kaggle driver notebooks (generated by kaggle/make_notebooks.py)
splits/task{1,2,3}/     selected example / image / question / pair IDs, probe sets, dev/eval splits
results/
  env/                  Kaggle environment reports, pip freeze, setup smoke test
  task{1,2,3}/<run>/    config used, training logs, resources, metrics, per-example outputs
figures/                plots generated from results/ (used in the report)
report/                 NeurIPS-format report sources
```

Not committed: raw datasets, model weights and recovery checkpoints. Checkpoints are backed up to a
private Hugging Face Hub repo (`pa3/common/hub.py`); every number in the report traces to a file in
`results/` produced by a command listed below.

## Environment

* Kaggle GPU image (PyTorch/CUDA as shipped) + `requirements.txt`.
* Exact versions of each session: `results/env/kaggle_env.json`, `results/env/pip_freeze.txt`;
  locked set: `requirements-lock.txt`.

## Running on Kaggle

1. Notebook settings: **Accelerator → GPU T4 x2**, **Internet → On**.
2. **Add-ons → Secrets**: attach `GH_TOKEN` (fine-grained GitHub PAT, *Contents: read & write* on this
   repo only) and `HF_TOKEN` (Hugging Face, write scope) to the notebook.
3. The first cell of every notebook in `kaggle/` is the same bootstrap: it reads the secrets, writes a git
   credential file, clones this repo to `/tmp`, and installs requirements. Results are pushed back with
   `pa3.common.gitsync.push`. Long runs are executed with **Save Version → Save & Run All (Commit)**.
